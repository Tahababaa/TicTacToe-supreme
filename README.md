# TicTacToe-supreme
 Tic-Tac-Toe - Java LLD:  A console-based Tic-Tac-Toe game developed using Java and Low-Level Design (LLD) principles. The game allows (n-1) players to take turns marking a n x n board with Symbols of choice, with the objective of getting single symbol marks in a row, column, or diagonal.
